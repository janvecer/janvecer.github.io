## Mathematical calculations and controls

The following dependency-free Node checks passed:

- `qa/information-revision.test.cjs`: Columbia trial/shock information,
  coarsening identity, analytic quadratic optima, numerical exact optimum,
  pricing-law invariance, positive-wealth endpoints, and the incomplete
  football-market allocation and growth decomposition.
- `qa/portfolio-tools.test.cjs`: existing portfolio optimizer certificates,
  decomposition, state claims, and utility/cash-reserve boundaries.
- `qa/lr-widgets.test.cjs`: widget mounting, shared state and event handling,
  binary inverse pricing, martingale identities, boundaries, and controls.
- `qa/discrete-v4.test.cjs`: shared price/log paths, geometric-series means,
  and explicit handling of extreme simulated prices.

The new comparison is checked against analytical sums and quadratic coefficients,
not only against values generated by its own chart. Numerical results reproduce
stock fractions 2/3, 0.7, approximately 0.745331, and 13/16, with the stated
expected-growth ranking and implementation gap.

## Math typesetting

The bundled MathJax renderer was run directly in Node on the rendered TeX,
without a browser or a remote dependency. Formula counts and parse results are
recorded in `qa/math-typesetting-summary.json`. This checks TeX parsing and
mathematical rendering. It is not a browser layout check.

Long new display equations were split into shorter aligned lines. Tables and
math containers have horizontal overflow handling; the new loss chart uses
responsive SVG and controls with labels and keyboard support.

## Browser verification limitation

An actual browser preview could not be completed in this environment. Chrome
launch was blocked by a sandbox socket restriction, and the requested execution
permission was rejected by the environment's approval policy. No new browser
screenshots or successful browser results are claimed for this revision.

Please run `quarto preview` locally before publishing, especially to inspect the
phone layout, collapsible navigation, new comparison controls, and presentation
cards. `qa/check-browser.cjs` remains available for browser verification in an
environment with Playwright and an available browser.

Older browser and numerical JSON reports are retained under
`qa/archive-pre-2026-10-11/`. They describe earlier versions and do not certify
the layout of this revised website.
